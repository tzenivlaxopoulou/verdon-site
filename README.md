# Verdon Website

Static multi-page website for `Verdon`, a landscaping and garden care business in Thessaloniki, Greece.

## Structure

- `index.html`: Home page with hero, benefits, service preview, project showcase, testimonials, and CTA
- `services.html`: Detailed service sections
- `about.html`: Brand story, mission, values, and local positioning
- `contact.html`: Contact details, validated form, map section
- `privacy-policy.html`: Base privacy page placeholder
- `terms.html`: Base terms page placeholder
- `assets/css/styles.css`: Shared responsive styling and design system
- `assets/js/main.js`: Sticky header, mobile menu, reveal animations, form validation
- `assets/images/*.svg`: Lightweight local placeholder visuals with a landscaping direction

## Suggested Assets / Image Direction

- Real photography can replace the SVG placeholders later.
- Recommended style:
  - Natural light garden photography
  - Residential courtyards and refined small-business exteriors
  - Detail shots of pruning, planting, and tidy pathways
  - Before/after compositions with the same framing
- Preferred mood:
  - Soft morning or late-afternoon light
  - Calm green palette
  - Clean, non-staged environments
